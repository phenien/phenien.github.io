# CopticLife

A comprehensive application dedicated to the Coptic Orthodox Christian community, providing spiritual resources, daily readings, and community support.

## Overview

CopticLife is designed to help members of the Coptic Orthodox Church stay connected with their faith through:

- Daily scripture readings and prayers
- Church calendar and feast days
- Liturgical texts and hymns
- Community events and news
- Educational resources about Coptic Christianity

## Features

- **Daily Readings**: Access daily scripture readings from the Synaxarium
- **Prayer Book**: Complete collection of Coptic Orthodox prayers
- **Church Calendar**: Stay updated with feasts, fasts, and holy days
- **Liturgical Resources**: Texts and audio for Divine Liturgy and services
- **Community Connection**: Find local churches and events
- **Multilingual Support**: Available in English, Arabic, and Coptic

## Getting Started

### Prerequisites

- Modern web browser (Chrome, Firefox, Safari, Edge)
- Internet connection for dynamic content

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/PHenien/CopticLife.git
   cd CopticLife
   ```

2. Open `index.html` in your web browser, or serve using a local server:
   ```bash
   python -m http.server 8000
   # or
   npx http-server
   ```

3. Navigate to `http://localhost:8000` in your browser
